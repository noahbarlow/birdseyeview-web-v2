N°01

What you’re
applying to.

// Cohort Brief

A twelve-month cohort of fifty operators — selection, therapy, biomarker recovery, and an annual gathering. Designed across physical, mental, emotional, and spiritual layers. The work is real. The cost is paid by sponsors.

Selection is rigorous because the work is rigorous. Phase one is reviewed anonymously by an independent committee. Phase two is a psychological evaluation through The Coming Home Project. Phase three is a physical proof-of-readiness challenge. Acceptance is non-negotiable on commitment.

Once accepted, the program runs weekly for fifty-two weeks — training, recovery, peer accountability, biomarker tracking, and the integration sessions that hold the whole system together.

// What you receive

$15–20K value per participant. $0 cost to accepted. Fully sponsor-funded.

N°02

Who this
is for.

// EligibilityThree audiences
N°01 // Military

Veterans

Any branch. Any era. Any rank. Selection is anonymous to branch in Phase 1 — what matters is the work in front of you, not the patch behind you.

N°02 // First Response

First Responders

Police, fire, EMS, federal, dispatch. The same exposure profile. The same need for long-term recovery. Same selection bar as the veteran lane.

N°03 // Carriers

Trauma Survivors

You don’t need to have served to have paid the cost. A small number of seats are reserved for civilians carrying weight that warrants this program.

Not for: passive help-seeking, anyone who can’t commit fifty-two weeks of weekly time, anyone looking for a credential instead of a change. We screen for genuine readiness, not credentials.
